# Tank Battle (Python)

A two-player top-down tank battle built with Pygame. Move, rotate, and fire to reduce your opponent's health to zero.

## Controls

- Player 1: `W/A/S/D` to move and rotate, `Space` to fire.
- Player 2: Arrow keys to move and rotate, `Right Ctrl` to fire.

## Run

```bash
python -m pip install pygame
python main.py
```

Press **Enter** after a win to restart the match.
